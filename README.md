# إشارة (Ishara) — Flask

تطبيق ويب لتعليم إشارات اليد والتعرّف عليها بدقة عالية.

## المعمارية

- **المتصفح:** MediaPipe لتتبع 21 مفصلًا لكل يد + رسم الهيكل.
- **Flask + نموذج حقيقي:** ExtraTrees (scikit-learn) يتدرّب على كلماتك تلقائيًا عند كل مثال جديد، مع DTW كاحتياطي.
- **ElevenLabs:** مقطع صوت مرة واحدة لكل كلمة يُحفظ على القرص.
- **لا يُرفع فيديو الكاميرا** — تُرسل متجهات المفاصل فقط إلى السيرفر المحلي.

أنت تضيف الكلمات → تسجّل أمثلة → يُعاد بناء النموذج → التعرّف من نموذجك.

## التشغيل

```bat
Start-Ishara.cmd
```

أو:

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
python app.py
```

افتح http://127.0.0.1:5173

## الصوت

ضع المفتاح في `dist/local-config.js` (انظر المثال) أو متغيرات البيئة `ELEVEN_API_KEY` / `ELEVEN_VOICE_ID`.

## اختبار الواجهة المحلية (بدون Flask)

```bash
npm run start:static
npm test
```

**تنبيه:** ليست مترجمًا معتمدًا للغة الإشارة. تعتمد الدقة على جودة أمثلة التدريب.
